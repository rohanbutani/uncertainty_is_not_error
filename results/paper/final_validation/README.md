# Focused final validation

Generated by `analysis/final_validation.py` from the frozen TriviaQA and PopQA banks.

- `pregen_and_risk_coverage.json` contains held-out incremental-AUROC results at L24/SLT,
  L24/TBG, and the TriviaQA L40/TBG SE site, plus every risk--coverage point and paired
  bootstrap interval. Seeds 42 and 43 use 2,048 training rows and all remaining rows once.
- `heldout_feature_confirmation.json` contains the disjoint 50/50 discovery/confirmation
  split, selected and confirmed feature IDs, sample sizes, label channel, and scope caveat.

TriviaQA's locally restored table predates persistence of the LLM-judge column, so this
focused run uses the prespecified deterministic F1>=50 robustness label there. PopQA uses
the stored LLM-judge label. The feature confirmation establishes repeated correctness
association within both semantic-entropy strata; it does not establish that the semantic-
entropy effect is equivalent to zero.

The broad historical re-test described in `notebooks/RETEST_DISSOCIATION_RESULTS.md` still
lacks its original compact `results/retest/*.json` and direction `*.npz` bundle. Those files
must be regenerated before claiming a complete release of every historical analysis.
